# CVMaster 路线图与审阅 checkpoints

状态：v0.1；每个 checkpoint 由 Codex 明确设计/验收范围，Workbuddy 实现后交由 Codex review。用户在每个 major checkpoint 收到具体审阅材料和操作路径。

## CP0 — 产品与工程基线（当前）

**目标**：锁定 MVP、架构边界、数据模型、主要风险和协作规则。  
**产物**：`AGENTS.md`、`PRD.md`、`TECHSTACK.md`、`DATABASE.md`、`UI.md`、`ROADMAP.md`。  
**用户查收**：确认 LaTeX 简历为 MVP 主目标；review 未决项与首版范围。  
**完成条件**：文档间一致；关键未决问题有负责人/checkpoint，不被误写为已决定。

## CP1 — 可运行应用骨架与设计系统

**目标**：部署到 Vercel 预览环境的电脑端网页工作台，呈现可拖拽旋转/缩放的 3D 粒子星图、空状态、建星面板和示例星球；投放区输入仅做内存态演示并标注 `Preview only — not saved`。采用真实页面组件，不把原型单文件直接当生产应用。  
**验收演示**：电脑端视口；星球可选择并聚焦、碎片与星球可区分、键盘可访问、减少动态效果生效、空状态→新建→开关面板。  
**用户查收**：3D 视觉方向、星球/碎片图例、粒子密度和交互手感、右侧面板比例、英文文案。  
**前置**：框架/依赖基线、部署项目和域名配置由实现准备；账号密钥不进入仓库。

## CP2 — 身份、数据库与素材入库

**目标**：Supabase Auth、profiles/experiences/materials、RLS/Storage policies；用户创建星球，粘贴链接或文字、上传文件并看状态。  
**验收演示**：两账户隔离；刷新后数据仍在；失败/重试/删除；私有文件链接不能跨用户访问。  
**用户查收**：登录体验、字段/权限、允许上传格式/大小和隐私提示。

## CP3 — AI 提取与证据校对

**目标**：接入用户自选的 provider/key/model/endpoint/protocol 配置与版本化 adapter；BYOK 安全管理；文字/公开网页/文件进入异步提取，形成可引用的 claims。
**验收演示**：展示原素材→提取 facts→来源跳转→确认/编辑/拒绝；provider 失败时不丢素材，不静默切换 provider。
**用户查收**：provider/model/endpoint/protocol 配置、目标域名和发给模型的数据范围、密钥管理 UX、确认状态和提取粒度。
**阻断决策**：在 CP3 实现前完成 ADR-001、ADR-003、ADR-004。

## CP4 — JD 匹配与简历编辑

**目标**：JD 输入/解析、要求项、素材匹配、模块选择和结构化简历编辑器。  
**验收演示**：匹配项可解释并关联证据；未确认事实不会静默进入简历；用户可调整顺序与文本。  
**用户查收**：匹配质量、简历模块、模板布局、语言/地区格式。

## CP5 — LaTeX 与 PDF 导出

**目标**：版本化模板渲染 `.tex`；安全编译并下载 PDF；错误可理解可重试。  
**验收演示**：特殊字符处理、长内容分页、编译失败恢复、`.tex` 与 PDF 内容一致。  
**用户查收**：首发模板样式、页数、字体、PDF 编译方案。  
**阻断决策**：CP5 前完成 ADR-002；不得直接在无隔离的主 Web 进程里运行任意 LaTeX 命令。

## CP6 — 发布准备

**目标**：删除/导出个人数据、成本配额、速率限制、可访问性、隐私说明、监控和运维 runbook。  
**验收演示**：账户隔离、导出与删除、限额/异常、电脑端和键盘路径。  
**用户查收**：发布候选版本、数据处理说明、限制和支持流程。
